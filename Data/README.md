# Data

## `parking_data.csv` (sample, included)

A small subset of the NYC Parking Violations dataset: 1,119 ticket rows (~190 KB) with the same 43 columns as the full dataset (see the column descriptions in the [main README](../README.md#dataset-columns)). Use it to try the notebooks quickly without downloading the full data.

## `Parking Dataset.csv` (full, not included)

The full dataset (~1.2 GB) is too large for GitHub and is not tracked. Get it from NYC Open Data ("Parking Violations Issued") or Kaggle ("NYC Parking Tickets"), upload it to your Azure Blob/ADLS container and point the Bronze notebook at it.
